# Taiwan 2068: Formosa

一款以台灣地景為靈感、使用 Unreal Engine 製作的獨立互動作品。

## 太魯閣體驗版

走進以太魯閣峽谷為靈感打造的未來場景，探索峽谷公路、隧道、溪谷與觀景區域。

[前往 Releases 下載 Windows 版](../../releases/latest)

## 安裝

1. 從 Releases 下載 ZIP。
2. 將 ZIP 完整解壓縮。
3. 執行 `Taipei2068.exe`。
